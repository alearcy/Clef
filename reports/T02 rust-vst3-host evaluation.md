**Specification:** [T02](../docs/specs/T02-engine-validation.md)
**Upstream pin:** `6c64cdffc6740cce0b4c5b6916724697b0ef9ff8` (`vst3-host` 0.11.1).
**Status:** Fresh-worker VST3 state-restore smoke gate fixed locally and verified; backend amendment awaiting agreement. T02 is not complete.

## Recommendation and Ownership

Use `rust-vst3-host` as the provisional T02 VST3 backend **with the verified local patch**, subject to the repository's foundation agreement. It already supplies lifecycle, native macOS editor, state, MIDI, processing-mode and host-service code that Clef would otherwise implement around raw bindings or an SDK bridge. This is a concrete alternative to the approved standalone C++/Objective-C++ bridge, not final engine adoption or a production-compatibility guarantee. The added ownership is one pinned dependency patch with an explicit regression test. [Patch and reproduction instructions](../patches/vst3-host/README.md).

Its built-in isolated API still must run outside Clef's audio-device callback: it clones/serializes audio blocks, uses a mutex and synchronous pipe exchanges, allocates reply buffers, and waits for responses. The response deadline starts after the blocking pipe write/flush, so it does not strictly bound the whole exchange. Clef must implement the approved bounded handoff, account for buffering latency, and enforce active-playback failure detection independently of slow preparation. A short diagnostic benchmark cannot remove those responsibilities.

## Root Cause and Fix

The initial fresh-worker restore accepted the AA Y7 snapshot and returned the same 901,919 state bytes, but the first realtime-mode render was silent. The later offline render after another restore produced sound. Opening the editor before realtime playback also produced sound, suggesting an initialization dependency.

Direct tracing established the actual mechanism:

1. Pianoverse initialization left **118 editor parameter values** queued in the host's `component_handler.parameter_changes`.
2. State restoration updated the component/controller, but did not clear that editor-to-processor queue. Of those queued values, **78 differed** from the newly restored controller values.
3. The next audio block's `drain_editor_edits` reapplied those older values, overwriting the restored processor state. A snapshot taken before that block could therefore be byte-identical while subsequent sound was wrong.
4. The editor case worked because newer editor feedback replaced the old values. The second restore worked because the first render had already consumed the stale queue. Neither is a reliable state-loading policy.

The [patch](../patches/vst3-host/0001-clear-stale-editor-values-on-state-restore.patch) adds nine production lines in `PluginImpl::load_state_with_context`: after suspending/deactivating processing, clear pending editor-to-processor values **before** applying the new component state. New callbacks generated by restoration or later user edits remain valid. The shared implementation serves both direct and isolated hosting. No special case for Pianoverse, forced GUI opening, sleep, or replay of every parameter is introduced.

The deterministic TestSynth regression sets a channel-level editor value to zero, queues its `performEdit`, then restores an audible snapshot and renders. **Before:** failure, `peak=0`. **After:** nonzero audio; an editor edit made after restoration still mutes the processor as expected. This confirms both the bug and preservation of later edits.

## GUI, Environment, and Evidence Limits

The user selected Grand Piano Y7 / AA Y7 for Pianoverse. Its isolated editor was opened and inspected through computer use; the user assisted with preset activation. The loaded preset name and visible parameter values were subsequently confirmed after a fresh-worker state restore without manually loading the preset again. Sound measurements were separate in-memory probes, not listening evidence. A temporary `.app` wrapper around the built helper allowed native UI targeting; it is not a packaged Clef application.

The empty Pianoverse instance produced silence because no piano was selected. The user correctly identified that precondition. A restricted-context load crashed the child, whereas an unrestricted load succeeded; the precise environmental cause was not established. The main probe survived, but this was not the controlled crash/hang fixture gate. No plugin installation, sample relocation, license changes, or preset-file edits were made. Third-party plugin code can write its own preferences/caches during startup/teardown; ZebraHZ logged such writes outside the sandbox.

An initial offline dependency-resolution attempt lacked cached CPAL metadata; after dependency download, the selected unit/build checks passed. An upstream `feature_coverage_tests` selection with CPAL disabled ran **zero tests**, because that file is gated on `cpal-backend`; it is not counted as evidence.

## Diagnostic Probe

This environment-specific example was added to the temporary upstream checkout, not to the application. The diagnostic flags were used only to isolate the failure. They are not product features or runtime workarounds. The matching patched helper must be built and copied into the temporary wrapper path in the builder. `--state PATH` restores the local opaque snapshot; no audio device is opened.

```rust
use std::time::{Duration, Instant};
use vst3_host::{
    midi::{MidiChannel, MidiEvent},
    AudioBuffers, ProcessMode, Vst3Host,
};
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let path = std::env::args().nth(1).ok_or("plugin path required")?;
    let mut host=Vst3Host::builder().sample_rate(48000.0).block_size(128)
        .helper_path("/private/tmp/clef-rust-vst3-host-review/Clef VST3 Review.app/Contents/MacOS/vst3-host-helper").with_process_isolation(true).response_timeout(Duration::from_secs(10)).build()?;
    let mut p = host.load_plugin(&path)?;
    let args: Vec<String> = std::env::args().collect();
    if let Some(i) = args.iter().position(|a| a == "--state") {
        let state = std::fs::read(args.get(i + 1).ok_or("state path required")?)?;
        eprintln!("STAGE restore_into_fresh_worker bytes={}", state.len());
        if args.iter().any(|a| a == "--start-before-restore") {
            p.start_processing()?;
        }
        if args.iter().any(|a| a == "--preset-context") {
            p.load_state_with_context(&state, &vst3_host::StateContext::preset())?;
        } else {
            p.load_state(&state)?;
        }
        if args.iter().any(|a| a == "--restore-twice") {
            p.load_state(&state)?;
        }
        if args.iter().any(|a| a == "--offline-before-restore") {
            p.set_process_mode(ProcessMode::Offline)?;
            p.load_state(&state)?;
            p.set_process_mode(ProcessMode::Realtime)?;
        }
        eprintln!("STAGE fresh_worker_state_restored");
        if args.iter().any(|a| a == "--reconfigure-after-state") {
            eprintln!("STAGE explicit_reconfigure_after_state");
            p.reconfigure(48000.0, 128)?;
            p.set_process_mode(ProcessMode::Realtime)?;
            p.service_host_requests()?;
        }
    }
    if args.iter().any(|a| a == "--query-editor-size") {
        eprintln!("STAGE query_editor_size {:?}", p.get_editor_size()?);
    }
    let initialize_editor = args.iter().any(|a| a == "--initialize-editor");
    if initialize_editor {
        assert!(p.isolation_pid().is_some());
        let parent = unsafe { vst3_host::WindowHandle::from_raw(std::ptr::null_mut()) };
        p.open_editor(parent)?;
        eprintln!("STAGE diagnostic_editor_open");
    }
    if let Some(i) = args.iter().position(|a| a == "--settle-ms") {
        let ms: u64 = args.get(i + 1).ok_or("settle duration required")?.parse()?;
        assert!(ms <= 30000);
        eprintln!("STAGE diagnostic_settle_ms={ms}");
        std::thread::sleep(Duration::from_millis(ms));
    }
    if initialize_editor {
        p.close_editor()?;
        eprintln!("STAGE diagnostic_editor_closed");
    }
    let editor = args.iter().any(|a| a == "--editor");
    if editor {
        assert!(p.isolation_pid().is_some());
        // The isolated implementation ignores the parent; upstream isolated_gui uses this handle.
        let parent = unsafe { vst3_host::WindowHandle::from_raw(std::ptr::null_mut()) };
        p.open_editor(parent)?;
        eprintln!("EDITOR READY: select a loaded piano, then press Enter in this probe to measure without a device.");
        let mut line = String::new();
        std::io::stdin().read_line(&mut line)?;
    }
    eprintln!("STAGE save_state");
    let state = p.save_state()?;
    eprintln!("STAGE state_saved bytes={}", state.len());
    if editor {
        std::fs::write("/private/tmp/clef-pianoverse-AA-Y7.state", &state)?;
    }
    if let Some(i) = args.iter().position(|a| a == "--snapshot-out") {
        std::fs::write(
            args.get(i + 1).ok_or("snapshot output path required")?,
            &state,
        )?;
    }

    let name = p.info().name.clone();
    let pid = p.isolation_pid().ok_or("plugin not isolated")?;
    let mut buf = AudioBuffers::new(0, 2, 128, 48000.0);
    eprintln!("STAGE configure_and_start");
    let preparation = Instant::now();
    p.set_tempo(100.0)?;
    p.set_playing(true)?;
    p.start_processing()?;
    eprintln!(
        "STAGE prepared elapsed_ms={}",
        preparation.elapsed().as_secs_f64() * 1000.0
    );
    p.send_midi_event_at(
        MidiEvent::NoteOn {
            channel: MidiChannel::Ch1,
            note: 60,
            velocity: 80,
        },
        37,
    )?;
    eprintln!("STAGE warmup");
    let mut peak = 0.0f32;
    for _ in 0..32 {
        p.process_audio(&mut buf)?;
        for &v in buf.outputs.iter().flatten() {
            peak = peak.max(v.abs());
        }
    }
    eprintln!("STAGE measured_realtime");
    if args.iter().any(|a| a == "--paced-warmup") {
        eprintln!("STAGE paced_readiness_probe");
        for block in 0..1125 {
            let start = Instant::now();
            if block % 64 == 0 {
                p.send_midi_note_off(60, MidiChannel::Ch1)?;
                p.send_midi_note(60, 80, MidiChannel::Ch1)?;
            }
            p.process_audio(&mut buf)?;
            for &v in buf.outputs.iter().flatten() {
                assert!(v.is_finite());
                peak = peak.max(v.abs());
            }
            if let Some(delay) =
                Duration::from_secs_f64(128.0 / 48000.0).checked_sub(start.elapsed())
            {
                std::thread::sleep(delay);
            }
        }
        eprintln!("STAGE paced_readiness_peak={peak}");
    }
    let mut samples = Vec::new();
    for block in 0..1000 {
        if args.iter().any(|a| a == "--poll-host") && block % 16 == 0 {
            let flags = p.service_host_requests()?;
            if !flags.is_empty() {
                eprintln!("CALLBACK restart bits={}", flags.bits());
            }
            for n in p.take_host_notifications() {
                eprintln!("CALLBACK notification {n:?}");
                if let vst3_host::HostNotification::BusActivationRequested {
                    media_type,
                    direction,
                    bus_index,
                    active,
                } = n
                {
                    p.set_bus_active(media_type, direction, bus_index, active)?;
                }
            }
            let edits = p.take_parameter_edits();
            if !edits.is_empty() {
                eprintln!("CALLBACK parameter edits {}", edits.len());
            }
            let blocks = p.take_data_exchange_blocks();
            if !blocks.is_empty() {
                eprintln!("CALLBACK data exchange {}", blocks.len());
            }
        }
        if block % 128 == 0 {
            p.send_midi_note_off(60, MidiChannel::Ch1)?;
            p.send_midi_note(60, 80, MidiChannel::Ch1)?;
        }
        let start = Instant::now();
        p.process_audio(&mut buf)?;
        samples.push(start.elapsed().as_secs_f64());
        for sample in buf.outputs.iter().flatten() {
            assert!(sample.is_finite(), "non-finite plugin output");
            peak = peak.max(sample.abs());
        }
    }
    p.send_midi_note_off(60, MidiChannel::Ch1)?;
    p.process_audio(&mut buf)?;
    if let Some(i) = args.iter().position(|a| a == "--snapshot-out") {
        let path = format!(
            "{}.realtime",
            args.get(i + 1).ok_or("snapshot output path required")?
        );
        std::fs::write(path, p.save_state()?)?;
        eprintln!("STAGE realtime_state_saved");
    }
    p.stop_processing()?;
    eprintln!("STAGE switch_offline");
    p.set_process_mode(ProcessMode::Offline)?;
    eprintln!("STAGE restore_state");
    p.load_state(&state)?;
    eprintln!("STAGE state_restored");
    p.service_host_requests()?;
    p.set_playing(true)?;
    p.start_processing()?;
    p.send_midi_note(60, 80, MidiChannel::Ch1)?;
    eprintln!("STAGE offline_render");
    let mut offline_peak = 0.0f32;
    for block in 0..1000 {
        if block % 128 == 0 {
            p.send_midi_note_off(60, MidiChannel::Ch1)?;
            p.send_midi_note(60, 80, MidiChannel::Ch1)?;
        }
        p.process_audio(&mut buf)?;
        for &v in buf.outputs.iter().flatten() {
            assert!(v.is_finite());
            offline_peak = offline_peak.max(v.abs());
        }
    }
    p.send_midi_note_off(60, MidiChannel::Ch1)?;
    p.process_audio(&mut buf)?;
    p.stop_processing()?;
    samples.sort_by(f64::total_cmp);
    let budget = 128.0 / 48000.0;
    println!("{{\"plugin\":{:?},\"pid\":{},\"state_bytes\":{},\"peak\":{},\"offline_peak\":{},\"latency_samples\":{},\"blocks\":1000,\"median_ms\":{},\"p99_ms\":{},\"max_ms\":{},\"exchanges_over_128_frame_budget\":{},\"sound_detected\":{}}}",
        name,pid,state.len(),peak,offline_peak,p.latency_samples(),samples[500]*1000.0,samples[990]*1000.0,samples[999]*1000.0,samples.iter().filter(|&&v|v>budget).count(),peak>0.0);
    if editor {
        eprintln!("STAGE close_editor");
        p.close_editor()?;
    }
    Ok(())
}
```
